# poetic-phrase-generator

Expérience JavaScript de génération de texte et d’image à partir d’un nom, d’une activité et d’un lieu.

[Interface du générateur](https://abdelhakim-baalla.github.io/poetic-phrase-generator/) · [Paramètres de génération](https://github.com/Abdelhakim-Baalla/poetic-phrase-generator/blob/main/index.js)

Depuis la racine, lancer `python3 -m http.server 8000` et ouvrir `http://localhost:8000`. Les paramètres de personnalisation sont regroupés dans `index.js`.
